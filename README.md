## 🎯 About

**Open Circle** is a community initiative under **OpenSkooll** that brings free, practical, hands-on workshops to students. 

**Workshop #1 — AI 101** covers:
- 🧠 **Shift 1:** Understand AI — What it really is, how LLMs work, what they can and can't do
- 🛠️ **Shift 2:** Learn the Tools — Hands-on with ChatGPT, Claude, Gemini & prompt engineering
- 🚀 **Shift 3:** Build Something Real — Create an AI-powered project from scratch
